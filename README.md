# ハコまる（デスクトップマスコット）

頭に芽の生えた箱のキャラクター「ハコまる」が、タスクバーの上を歩き回る Electron アプリです。

## 起動方法

```bash
npm install
npm start
```

## できること

- タスクバー（画面下端）の上をぶらぶら歩く。歩行は4コマで、進んだ距離ぶんだけコマが進むので足がすべらない
- 歩き出しは加速、止まる前は減速。振り向くときは一瞬ためてから向きを変える
- 足音に合わせて砂ぼこりが出る。体は一歩ごとに上下し、頭の芽も遅れて揺れる
- クリックでジャンプしてしゃべる
- ドラッグでつかめる（引っぱる向きに傾き、足をぷらぷら）。離すと投げた勢いで落ち、着地でつぶれる
- 透明な部分はクリックが下のウィンドウに通る（Windows / macOS）
- 右クリックかタスクトレイからメニュー：歩く ON/OFF、おやすみ、起こす、マウスの位置に呼ぶ、大きさ（1〜10）、ログイン時に起動、終了
- 大きさは 10＝標準、1＝半分。選んだ大きさは保存され、次回起動時も引き継がれる
- 起動時のあいさつ、毎時のお知らせ、夜は眠くなりやすい

## カスタマイズ

- 色：`renderer.js` の `C`
- セリフ：`LINES_POKE`、`greeting()`
- 歩く速さ：`WALK_SPEED`（歩行コマの速さは自動で追従します）
- キャラの形：`drawCharacter()`（1ドット＝4px のドット絵座標で描いています）

## 配布用にビルドする場合

`electron-builder` などでパッケージ化できます。

```bash
npm install --save-dev electron-builder
npx electron-builder
```

## 注意

Linux ではクリック透過の転送に対応していないため、ウィンドウ全体（200×180px）がクリックを受け取ります。
