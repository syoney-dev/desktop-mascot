# ハコまる（デスクトップマスコット）

頭に芽の生えた箱のキャラクター「ハコまる」が、タスクバーの上を歩き回る Electron アプリです。
メニューの「キャラクター」で、白地に黒ぶちの子猫「にゃんまる」にも切り替えられます。

## ダウンロード（Windows）

**[最新版のダウンロードページ](https://github.com/syoney-dev/desktop-mascot/releases/latest)** から `Hakomaru-Setup-<バージョン>.exe` をダウンロードして、ダブルクリックするとインストールされます（管理者権限は不要）。

- コード署名をしていないため、初回は「Windows によって PC が保護されました」と表示されます。「詳細情報」→「実行」で起動できます

### インストールで行われること

インストーラーをダブルクリックすると、次の順に進みます。インストール先は聞かれず、管理者権限もいりません。変更されるのは、そのユーザーの範囲だけです。

1. アプリ本体（約 370MB）を `%LOCALAPPDATA%\Programs\ハコまる\` に展開する
2. スタートメニューとデスクトップにショートカットを作る
3. Windows の「アプリ」一覧に登録する（アンインストール用）
4. ハコまるを起動する

### アンインストール

- 「設定」→「アプリ」→「インストールされているアプリ」で「ハコまる」の「…」→「アンインストール」
- または `%LOCALAPPDATA%\Programs\ハコまる\Uninstall ハコまる.exe` を実行

アンインストールしても、次のものは残ります。

- 設定ファイル（大きさ・キャラ・育成の状態など）：`%APPDATA%\ハコまる\`。入れ直すと状態が引き継がれます。完全に消すときは、このフォルダーも削除してください
- 「ログイン時に起動」の登録：オンにしていた場合は残ることがあるので、アンインストールする前にメニューでオフにしてください

## ソースから起動する（開発用）

```bash
npm install
npm start
```

## できること

- タスクバー（画面下端）の上をぶらぶら歩く。歩行は4コマで、進んだ距離ぶんだけコマが進むので足がすべらない
- 歩き出しは加速、止まる前は減速。振り向くときは一瞬ためてから向きを変える
- 足音に合わせて砂ぼこりが出る。体は一歩ごとに上下し、頭の芽も遅れて揺れる
- クリックでジャンプしてしゃべる。鳴き声も出る（電子音をその場で合成。寝ているときはびっくりした声）
- ドラッグでつかめる（引っぱる向きに傾き、足をぷらぷら）。離すと投げた勢いで落ち、着地でつぶれる
  - にゃんまるは首根っこをつままれてぶらーん。投げると足をのばしてジャンプし、落ちてくるときは足を下にして着地する
- 透明な部分はクリックが下のウィンドウに通る（Windows / macOS）
- 右クリックかタスクトレイからメニュー：水をあげる（ハコまるのみ）、鳴き声 ON/OFF、歩く ON/OFF、おやすみ、起こす、マウスの位置に呼ぶ、キャラクター、大きさ（1〜10）、ログイン時に起動、終了
- キャラクターを切り替えると、トレイのアイコンと名前もそのキャラになる。選んだキャラは保存される
- 大きさは 10＝標準、1＝半分。選んだ大きさは保存され、次回起動時も引き継がれる
- 起動時のあいさつ、毎時のお知らせ、夜は眠くなりやすい
- 育成（ハコまるのみ）：メニューの「水をあげる」で頭の植物が育つ（1日1回ぶん）。水やり3日で双葉、6日でつぼみ、10日で花。咲いてから3日水をあげると種ができて芽に戻り、次は別の色の花が咲く
- 決して死なない。2日以上水をあげないと葉がしおれて「のどかわいたな…」と言うが、水をあげればすぐ元気になる
- しばらく起動していなかったら「ひさしぶり！」（1日以上）「あいたかったよ〜！」（3日以上）とあいさつする

## カスタマイズ

キャラごとの見た目・動き・セリフ・鳴き声は `skins/` にあります（`skins/hakomaru.js`、`skins/nyanmaru.js`）。

- 色：各スキンの `C`
- セリフ：各スキンの `lines`
- キャラの形：各スキンの `draw()`（1ドット＝4px のドット絵座標。足元が (0, 0)、右向きで描く）
- ポーズ：各スキンの `pose()`（歩く・つかまれる・落ちる・寝るときの形）
- 鳴き声：各スキンの `voice()`
- 歩く速さ：`renderer.js` の `WALK_SPEED`（歩行コマの速さは自動で追従します）
- 育つ早さ：`renderer.js` の `GROW_DAYS`、`SEED_DAYS`、しおれるまでの日数：`THIRSTY_DAYS`

### キャラを増やすには

1. `skins/hakomaru.js` をまねて `skins/<名前>.js` を作る（`pose()`・`draw()`・`lines`・`voice()` などをそろえる）
2. `index.html` に `<script src="skins/<名前>.js">` を足す（`renderer.js` より前）
3. `main.js` の `SKINS` に `{ id, name, care }` を足す

## 配布用にビルドする

```bash
npm run dist
```

`dist/Hakomaru-Setup-<バージョン>.exe` ができます。これ1つを配ればOKです。

- ダブルクリックするとすぐにインストールされ、スタートメニューとデスクトップにショートカットができます（管理者権限は不要）
- アンインストールは Windows の「設定 → アプリ」から
- コード署名をしていないので、初回は SmartScreen の「Windows によって PC が保護されました」が出ます。「詳細情報 → 実行」で起動できます
- 配る前に `package.json` の `version` を上げておくと、上書きインストールで更新できます

アプリのアイコン（`build/icon.png`）は `skins/hakomaru.js` の絵から作っています。トレイのアイコンは、起動中に選んでいるキャラの絵から自動で作ります。見た目を変えたら作り直してください。

```bash
npm run icon
```

## 注意

Linux ではクリック透過の転送に対応していないため、ウィンドウ全体（200×180px）がクリックを受け取ります。
